Énoncé

Algorithmique · Facile

Écrivez une fonction tri_croissant(liste) qui renvoie une nouvelle liste contenant les mêmes éléments, triés par ordre croissant.

Interdit : sorted() et list.sort(). La liste d’origine ne doit pas être modifiée.

Votre code Python

Environnement isolé · limite 2 s par test
1def tri_croissant(liste):
2    resultat = list(liste)
3    for i in range(len(resultat)):
4        for j in range(0, len(resultat) - i - 1):
5            if resultat[j] > resultat[j + 1]:
6                resultat[j], resultat[j + 1] = resultat[j + 1], resultat[j]
7    return resultat
